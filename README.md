## Entry

> My smart fridge makes me knock twice to see inside it — I paid $3,000 for an appliance with the boundaries of a moody teenager.

## How it works

`main.py` writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` when unset) as a single line with no trailing
newline. Before writing, it validates the kit gate exactly: the text
must be UTF-8, 1–200 characters, not only whitespace, and a single line.

## Run

```sh
python3 main.py
```
